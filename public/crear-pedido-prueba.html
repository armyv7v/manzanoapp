Crear Pedido de Prueba

Este pedido disparará la Cloud Function que envía notificaciones.

📋 Instrucciones

Después de crear el pedido:

1. Espera 5-10 segundos
2. Deberías recibir una notificación push
3. Si no llega, ve a Firebase Console → Functions → Logs
4. Busca logs de sendNewOrderNotification
5. Revisa si hay errores
